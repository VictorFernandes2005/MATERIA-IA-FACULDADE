# Reavaliação do dataset Iris com SVM usando Kaggle Notebook
"Nesta atividade, cada aluno deverá realizar a reavaliação do dataset Iris utilizando dados obtidos diretamente do [Kaggle](https://www.kaggle.com/), criando o notebook a partir da página do dataset, realizando análise exploratória dos dados e desenvolvendo um modelo de classificação usando exclusivamente Support Vector Machine (SVM)."

## Objetivos da atividade
- Utilizar dados externos obtidos do Kaggle
- Criar Notebook vinculado ao dataset
- Realizar Análise Exploratória de Dados (EDA)
- Desenvolver modelo de classificação com SVM
- Avaliar desempenho com métricas clássicas
- Documentar todo o workflow de Machine Learning
- Produzir notebook reprodutível e bem comentado
