# Atividade Prática:  classificação com SVM (Support Vector Machine)
---
Essa atividade tem como objetivo aplicar os conhecimentos aprendidos anteriormente, configurando e treinando uma Machine Learning, utilizando o modelo de classificação do Support Vector Machine (SVM) com o conjunto de dados Iris.

A atividade segue as seguintes etapas:
- Explorar os dados
- Treinar modelos SVM (linear e não linear)
- Comparar resultados
- Testar diferentes parâmetros
