# Atividades de Data Science: NumPy, SciPy, Pandas e Matplotlib
---
Essa atividade tem como objetivo, aprender os fundamentos e treinar as funcionalidades das principais bibliotecas Python utilizadas em Data Science.

São 80 questões, dividas entre 20 questões de [Numpy](https://numpy.org/), [Scipy](https://scipy.org/pt/), [Pandas](https://pandas.pydata.org/) e [MatplotLib](https://matplotlib.org/)

Os exercícios foram feitos utilizando o [Google Collab](https://colab.research.google.com/)
